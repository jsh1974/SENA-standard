# 🌐 SENA Language Specification (v1.0)
**S**encillo · **E**ficiente · **N**eutro · **A**SCII

## 1. Introducción / Introduction
**ES:** SENA es un protocolo de comunicación lógico diseñado para humanos y máquinas. Su objetivo es eliminar la ambigüedad y reducir la complejidad del lenguaje natural.
**EN:** *SENA is a logical communication protocol designed for humans and machines. Its goal is to eliminate ambiguity and reduce the complexity of natural language.*

---

## 2. Reglas de Oro / Core Rules
1. **Sintaxis (SVO):** Sujeto + Verbo + Objeto.
2. **Verbos Invariables:** El verbo no se conjuga. El tiempo lo define una partícula previa.
3. **Neutralidad:** No existe el género gramatical. `ta` es el pronombre universal.
4. **Plural:** Se añade `-s` al final de cualquier sustantivo o pronombre.
5. **Adjetivos:** Se colocan siempre después del sustantivo (`domo granda`).
6. **Ortografía ASCII:** Solo caracteres estándar. Sin tildes, eñes o signos de puntuación innecesarios.

---

## 3. Gramática Técnica / Technical Grammar

### Partículas de Tiempo / Temporal Particles
- `nu` : Presente / Present
- `pa` : Pasado / Past
- `fu` : Futuro / Future
- `ja` : Completado / Completed
- `si` : Condicional / Conditional

### Pregunta y Negación / Question and Negation
- `ka` : Partícula de inicio para preguntas. No usar signos de interrogación.
- `no` : Negación simple.
