# ✍️ Guía de Estilo SENA / SENA Style Guide (v1.0)

**ES:** Esta guía establece las reglas para mantener la consistencia técnica del protocolo.
**EN:** *This guide establishes the rules to maintain the technical consistency of the protocol.*

---

## 1. Estructura de Tiempo / Tense Structure

**ES:** El tiempo gramatical siempre precede al verbo. Nunca se debe conjugar la raíz.
**EN:** *The grammatical tense always precedes the verb. The root must never be conjugated.*

* **ES:** [Partícula de tiempo] + [Verbo]
* **EN:** *[Tense particle] + [Verb]*
* **Ejemplo / Example:** `mi fu labo` (Yo trabajaré / *I will work*)

---

## 2. Orden de los Adjetivos / Order of Adjectives

**ES:** Los adjetivos se sitúan estrictamente después del sustantivo para facilitar el procesamiento de datos.
**EN:** *Adjectives are strictly placed after the noun to facilitate data processing.*

* **Regla / Rule:** `[Sustantivo] + [Adjetivo]`
* **Ejemplo / Example:** `auto rapia` (coche rápido / *fast car*)

---

## 3. Formato de Preguntas / Question Format

**ES:** Está prohibido el uso de signos de interrogación. Se debe usar la partícula `ka` al inicio de la frase.
**EN:** *The use of question marks is prohibited. The particle `ka` must be used at the beginning of the sentence.*

* **Regla / Rule:** `ka` + [Sujeto] + [Verbo] + [Objeto]
* **Ejemplo / Example:** `ka ta nu veni` (¿Él viene? / *Is he coming?*)

---

## 4. Adaptación ASCII / ASCII Adaptation

**ES:** No se permiten caracteres fuera del set ASCII estándar (ISO 646).
**EN:** *Characters outside the standard ASCII set (ISO 646) are not allowed.*

* **ES:** Sustituir letras especiales por combinaciones ASCII simples (ej: ñ -> ni).
* **EN:** *Substitute special letters with simple ASCII combinations (e.g., ñ -> ni).*

---

## 5. Nombres Propios / Proper Names

**ES:** Los nombres propios deben mantener la capitalización inicial para distinguirse de las raíces.
**EN:** *Proper names must maintain initial capitalization to be distinguished from roots.*

* **Ejemplo / Example:** `mi nu idi a Roma` (Yo voy a Roma / *I am going to Rome*)
